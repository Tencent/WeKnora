# 飞书云文档块解析

仅在 `FEISHU_DOCX_PARSE_MODE=blocks` 时生效。`export` 模式整篇导出 `.docx`，不走块下钻。

Wiki / 云盘里独立的 `obj_type=board` 节点仍不支持，本文只覆盖 **docx 内嵌画板（`block_type=43`）** 以及同路径下的表格与子目录。

## 行为

| 能力 | 说明 |
|------|------|
| 内嵌画板（`block_type=43`） | `board.token` → `GET /board/v1/whiteboards/{id}/download_as_image`（按二进制读取；JSON 错误体视为失败）→ 裁近白边 → 独立图片子条目。metadata：`embedded_image=true` + `whiteboard=true`。失败只跳过该画板，不拖垮整篇。 |
| Markdown 占位符 | `![图片](image-{token}.png)` / `![画板](board-{wid}.png)`，与子条目 FileName 对齐。 |
| 内嵌 sheet（`block_type=30`） | `valueRenderOption=FormattedValue`（公式/数字取显示值）。富文本单元格为段数组时拼接各段 `text`，避免把对象打成 `[{...}]`。 |
| 子目录 | 父文档与附件/图片/画板的 `FileName` 为 `{sanitize(标题)}/{basename}`，由入库路径拆成知识库文件夹。 |

额外权限：`board:whiteboard:node:read`。缺失时该画板跳过，正文仍同步。
