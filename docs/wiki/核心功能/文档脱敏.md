# 文档脱敏

完整说明（预置类型、校验、打码样式、自定义正则、入库位置）见：[文档脱敏](../../文档脱敏.md)。

## 摘要

知识库级、**默认关闭**。解析出 Markdown 后、切块前打码。只处理文本，不改原件、不处理图片。库存标题和自定义元数据保持明文，进 Embedding / 摘要 / 问题生成前再打码。

**无法保证全部检出。** 未命中内容会原样进入向量和问答，不能替代人工复核。

内置引擎：正则 → 清洗 → 校验位 / 号段 / 结构 → 打码。一期预置覆盖大陆身份证、手机、固话、银联卡、统一社会信用代码、民用车牌、邮箱。护照和非银联卡不预置。

开启后不能使用云解析。脱敏失败则该文档解析失败（fail-closed）。已入库文档不会回溯打码。
