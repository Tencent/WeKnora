# 智能体提示词模板

系统内置了多套智能体系统提示词模板，可在创建或编辑智能体时直接选用，无需从零编写提示词。本文重点介绍 **Wiki 内容生成**、**Wiki 提取重点**、**图谱抽取专家** 三个面向知识库配置优化的模板。

## 概述

在 **智能体编辑 → 提示词 → 系统提示词** 右上角点击「使用模板」，即可从下拉列表中选择内置模板并一键应用。模板遵循 WeKnora 统一规范，支持多语言名称展示。

以下三个模板专门用于辅助知识库配置：用户上传示例文档后，由智能体分析并输出可直接粘贴到知识库设置中的指令文本。

| 模板名称 | 模板 ID | 用途 | 输出粘贴位置 |
|---------|---------|------|------------|
| Wiki 内容生成 | `wiki_content_generator` | 分析文档，生成 Wiki 内容风格与重点的指导性说明 | 知识库编辑 → Wiki → 内容生成要求 |
| Wiki 提取重点 | `wiki_extraction_focus` | 识别文档中的核心实体与关键概念类别 | 知识库编辑 → Wiki → 提取重点 |
| 图谱抽取专家 | `graph_extraction_specialist` | 从文档中抽取标签、实体、关系三元组 | 知识图谱设置 → 额外提取要求（或直接作为抽取参考） |

## 使用流程

1. 进入 **智能体** 页面，点击「新建智能体」
2. 运行模式选择 **快速问答**，填写名称和描述
3. 进入「提示词」→「系统提示词」，点击右上角「使用模板」
4. 选择对应的模板（如「Wiki 内容生成」）
5. 保存智能体
6. 在对话中上传一份你的领域示例文档，让智能体分析
7. 将智能体输出的结果复制到知识库对应配置项中

> 注意：模板仅为辅助生成配置指令的工具，输出结果建议根据实际业务需求做微调后再使用。

## Wiki 内容生成模板

**适用场景**：新建 Wiki 知识库时，不知道如何填写「内容生成要求」，上传一份代表性文档，让智能体帮你生成。

**输出内容涵盖**：
- 语气与风格（技术文档 / 产品手册 / 法律文书等）
- 内容重点（应强调的主题、实体、概念）
- 结构偏好（页面层级与章节组织）
- 关键信息提取（版本号、日期、负责人、参数等）
- 引用与防幻觉规则

**字数控制**：输出会控制在 4000 字符以内，可直接粘贴到配置框。

## Wiki 提取重点模板

**适用场景**：新建 Wiki 知识库时，需要告诉系统应重点识别哪些实体和概念以生成独立 Wiki 页面。

**输出内容涵盖**：
- 领域判断（文档类型与所属领域）
- 核心实体类别（应提取的实体类型及示例）
- 核心概念类别（应建 Wiki 页面的主题类别）
- 提取优先级（哪些值得独立建页，哪些作为子章节）
- 命名规范（保持原文 / 翻译 / 正式术语等）

**字数控制**：输出会控制在 4000 字符以内，可直接粘贴到配置框。

## 图谱抽取专家模板

**适用场景**：启用知识图谱后，希望了解系统会从文档中提取出什么样的实体和关系，或需要为「额外提取要求」提供参考文本。

**输出内容分为三部分**：
1. **标签（Tags）** — 5-10 个覆盖领域的核心标签
2. **实体（Entities）** — 与领域强相关的技术/业务实体
3. **关系（Relations）** — 实体间的显式关系（头实体 - 关系 -> 尾实体）

**内置 7 个领域候选池**：
- 技术教程 / API 文档 / 编程语言与框架
- 通用技术说明（架构、产品手册、配置指南）
- 法律 / 合同文书
- 学术论文 / 研究报告
- 半导体硬件配置参数文档
- 行业标准文档
- 半导体工序与生产制造文档

智能体会自动判断文档类型并从对应候选池中筛选，若不在列表中则自行归纳。
