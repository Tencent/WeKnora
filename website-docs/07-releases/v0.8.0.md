# v0.8.0 版本说明

发布日期：2026-09-03

v0.8.0 的主题是让智能体能够真正动手完成任务：技能成为空间内统一管理的资源，在会话级沙箱中执行脚本、处理文件并生成交付物；新增跨会话的长期记忆，让智能体记住你确认过的偏好和信息。此外，Office 文档可以在应用内直接解析，并新增 GitLab、腾讯 IMA 数据源、LiteLLM 模型接入和 DeepSeek Harness 插件。

从 v0.7.x 升级前，请先阅读[升级须知](#upgrade-notes)。完整的变更列表见 [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md)。

## 技能沙箱 {#skill-sandbox}

智能体的技能在会话级沙箱中运行：每个对话有一个独立的沙箱，多轮任务共用同一个工作区。执行命令、读写和编辑文件、处理上传的附件、收集生成的文件，都在这个工作区里完成。

<Screenshot
  src="/screenshots/skill-sandbox-chat.png"
  caption="智能体根据知识库生成 Word 文档，并在对话旁预览生成的文件" />

- **三种后端**：Docker（单机或自建）、E2B（云端或兼容 E2B 的自建控制面）、CubeSandbox，使用同一套远程协议。
- **按空间配置**：镜像、CPU / 内存、存活时间、DNS、模板和快照都可以按空间配置；管理员还可以为每个配置设置网络策略，例如默认禁止出站、允许 / 拒绝列表。
- **Docker 后端默认关闭**：挂载 `docker.sock` 等同于宿主机 root 权限，需要在「系统设置 → 网络安全」中开启，或设置 `WEKNORA_SANDBOX_DOCKER_ENABLED=true`。
- **生成文件**：沙箱中生成的文件汇总到每条消息的产物抽屉，可以预览和下载，有新文件时会有提示。
- **长任务压缩**：沙箱中的长时间任务会压缩工具调用历史，而不是截断或改写文件；稳定的提示词前缀加上缓存标记，可以提高 Anthropic 和 OpenAI 兼容接口的缓存命中率。每轮对话的 token 用量也会记录下来。

详见[技能目录与沙箱](../03-features/22-skills-sandbox.md)与[沙箱部署与排障](../06-development/04-sandbox-deployment.md)。

## 空间技能目录 {#skill-catalog}

技能成为空间内的一等资源，不再是放在服务进程旁边的文件。

<Screenshot
  src="/screenshots/skill-catalog.png"
  caption="空间技能目录：各技能及其安装到的沙箱" />

- **多种安装来源**：ClawHub、SkillHub / skills.sh、GitHub / GitLab 链接，或上传 ZIP。
- **按沙箱安装**：每次安装都会在所选沙箱配置上生成一个快照，实时显示安装进度和安装记录，可以中途停止、重新安装；从沙箱卸载时保留目录中的安装包。
- **在线查看与编辑**：可以在设置中浏览和编辑已安装技能的文件；智能体也可以通过 `write_skill_file`、`edit_skill_file` 修改技能文件，`shell_exec` 不再要求必须先安装技能。
- **环境变量**：个人和空间级的技能环境变量在执行时注入，保存后不会再被读出。
- 用 `@` 提及技能时，不再意外缩小智能体可用的技能范围。

## 跨会话长期记忆 {#memory}

新的长期记忆能力，与 v0.7.1 移除的基于 Neo4j 的对话记忆相互独立。

- **按需开启**：空间开启后，每个用户还可以自行关闭。
- **分类记忆**：记忆分为资料、偏好、事实、事项、兴趣五类，可以显式写入，也可以由后台自动提取。
- **由你确认**：自动推断出的记忆在你确认之前处于待确认状态，不会直接生效。
- **使用方式**：资料和偏好在每轮对话中都会带上；情境类事实按关键词召回，也可以开启语义召回；智能体可以用 `search_memory` 按需查询。经常引用的文档会在检索时获得更高的权重。
- 设置、条目、主题、文档关联、确认 / 拒绝、导出和强制整理都通过 `/api/v1/memory/*` 提供，仅限完整权限的 API Key，操作对象始终是调用者本人。

详见[长期记忆](../03-features/23-memory.md)与[长期记忆 API](../04-api/02-api-memory.md)。

## 文档解析与数据源 {#parsing-and-sources}

- **应用内 anydoc 解析**：doc、docx、ppt、pptx 等 anydoc 能转换的 Office 文档可以直接在 Go 应用内解析，不再绕道 docreader。应用镜像默认链接 anydoc。
- **XMind 大纲解析**：`.xmind` 文件会解析成大纲，与其他文档一样建立索引。
- **文档自动打标签**：解析完成后，对话模型可以从知识库已有的标签中挑选合适的标签，增量添加，不会新建标签，也不会覆盖手动添加的标签。
- **GitLab 与腾讯 IMA 数据源**：GitLab 项目可以作为知识来源同步；腾讯 IMA 笔记通过笔记 OpenAPI 同步，遇到临时错误会自动重试。
- **解析质量**：DOCX 的纵向合并单元格和表格文本得以保留；PDF 内嵌图片不再出现全黑；网页抓取失败时直接报错，不会把错误页面收进知识库。

详见[文档解析](../03-features/03-document-parsing.md)与[数据源导入](../03-features/10-datasource.md)。

## 模型、搜索与生态 {#ecosystem}

- **LiteLLM**：作为一等厂商接入对话、向量和重排模型，一个网关地址即可转发到多个上游模型。
- **Exa 与秘塔搜索**：新增两个联网搜索服务商。
- **DeepSeek Harness 插件**：官方 npm 包 [`@wxg-prc-cpg/dsh-weknora`](https://www.npmjs.com/package/@wxg-prc-cpg/dsh-weknora) 提供 `weknora_search`、`weknora_read_document`、`weknora_ask`、`weknora_list_knowledge_bases` 四个只读工具，让 DeepSeek Harness 编码智能体可以检索 WeKnora 中的知识。详见 [DeepSeek Harness](../05-clients/08-deepseek-harness.md)。

## 对话体验 {#chat}

- 较长的对话会显示问题目录，方便快速定位；消息之间按时间显示分隔。
- `shell_exec` 以「命令 + 输出」卡片的形式展示；工具卡片上会显示沙箱文件列表和技能名称。
- 流式输出过程中，Mermaid 图表保持渲染状态，不再反复闪烁。

## 账号与安全 {#security}

- **OIDC 签名校验**：ID Token 通过 JWKS 校验签名；新增 `/auth/oidc/start`，可以直接跳转登录。
- **可选的复杂密码**：开启后，注册、修改密码和管理员重置密码都要求包含大小写字母、数字和特殊字符（`WEKNORA_AUTH_COMPLEX_PASSWORD_ENABLED` 或系统设置）。
- **管理员创建用户**：平台管理员可以在控制台直接创建用户，不再需要邀请链接。
- **邀请流程**：邀请已注册的用户时可以自动接受；仅邀请模式下，分享链接会先引导访客登录再加入空间。
- **沙箱安全**：Docker 沙箱中的所有执行都以沙箱用户（uid 1000）运行，关闭了可能逃出工作区的符号链接操作，并会回收被取消执行留下的僵尸进程。

## 升级须知 {#upgrade-notes}

| 变化 | 需要做什么 |
| --- | --- |
| 移除了宿主机进程（Local）沙箱后端 | 原有的 Local 沙箱配置需要改用 Docker（需手动开启）、E2B 或 Cube 重新创建 |
| Docker 沙箱后端默认关闭 | 在「系统设置 → 网络安全」中开启，或设置 `WEKNORA_SANDBOX_DOCKER_ENABLED=true` |
| 开启复杂密码后，不符合规则的注册、修改密码请求会被拒绝 | 开启前通知用户新的密码要求 |

数据库迁移：PostgreSQL 为 `000080`–`000090`，SQLite 为 `000003`–`000012`。Docker 沙箱后端要求 app 容器中的 `appuser` 属于 `docker.sock` 所在的用户组。

## 其他改进与修复 {#other-changes}

- **检索**：MMR 选择改为增量计算；混合检索遵循 `resource_urls=public`；`MatchCount=0` 不再截断全部结果；已删除的图片不会再被检索到。
- **IM**：飞书长连接支持反向代理，流式卡片在全量输出模式下会显示进度；企业微信、钉钉、云之家的若干兼容性改进；IM 问答支持文件附件。
- **空间与文档**：切换空间时会记住上次使用的空间；支持在个人设置中修改密码；按目录拖拽上传会保留目录结构；文档摘要可编辑，分块列表分页显示。
- **部署能力**：未注册的模块会在菜单和设置中隐藏（`GET /system/capabilities`），Lite 等精简版本不再显示缺失的功能。
- **问题修复**：高风险系统设置读取最新保存的值；飞书流式卡片不再卡在进行中；被引用的模型删除时会显示引用详情；共享知识库在智能体上下文中的文档数不再为 0；内置智能体的名称和描述跟随界面语言。

完整列表见 [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md)。
