# v0.8.2 版本说明

发布日期：2026-09-24

v0.8.2 让智能体走出对话框：它可以操作你电脑上的浏览器；知识库可以作为 MCP Server 发布给 Claude、Cursor 等其他 AI 工具；对话过程也更可控，可以中途补充要求、分叉或回滚。沙箱新增交互终端和图形桌面，模型接入改为按厂商目录自动配置，另有 Confluence、钉钉文档数据源和日语界面等更新。

从 v0.8.0 升级前，请先阅读[升级须知](#upgrade-notes)。完整的变更列表见 [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md)。

## 本机浏览器 {#local-browser}

智能推理对话可以直接操作你电脑上的 Chrome 或 Edge。浏览器通过腾讯开源的 [BrowserSkill](https://github.com/Tencent/BrowserSkill) 扩展连接到 WeKnora，智能体在独立的任务窗口中打开网页、点击、填写表单、读取内容，再把结果汇报到对话里。

<Screenshot
  src="/screenshots/local-browser-task.png"
  caption="智能体查询 GitHub 最新 Release 后填写订单表单，对话右下角是任务预览" />

- **对话中可控**：任务预览显示在对话里，可以随时暂停、继续或结束，也可以跳到浏览器查看对应页面。
- **需要人时交给人**：遇到登录、验证码或需要授权的步骤，智能体会发起人工协助；你在浏览器里处理完，它再接着执行。
- **一次配对，多处可用**：在「工具箱 → 浏览器连接」复制配对链接，粘贴到扩展里即可。同一空间内的多个对话共用这台浏览器的授权，开启输入框的「本机浏览器」开关后才会使用。

<Screenshot
  src="/screenshots/browser-connection.png"
  caption="工具箱 → 浏览器连接：扩展版本、连接状态与智能体可执行的网页操作" />

Docker 部署的 app 镜像已内置 BrowserSkill 服务和配套扩展，通常无需额外配置；多副本部署需要配置节点互通地址和共享密钥。详见[本机浏览器](../05-clients/09-local-browser.md)。

## 内置 MCP Server {#mcp-server}

每个空间都可以把知识库发布为 MCP 服务，供 Claude Desktop、Cursor、Claude Code、VS Code 等支持 MCP 的客户端直接检索和提问，无需再单独部署 MCP 进程。

<Screenshot
  src="/screenshots/mcp-server-endpoint.png"
  caption="设置 → 发布集成 → MCP Server：端点地址与客户端配置" />

- 在「设置 → 发布集成 → MCP Server」新建端点，选择可访问的知识库和要开放的工具。
- 工具分四组：检索与阅读、问答（运行端点指定的智能体）、Wiki、写入；写入工具默认关闭。
- 每个端点有独立的令牌和调用频率上限（默认每分钟 60 次），令牌可以随时轮换。
- 页面直接给出 Cursor、VS Code、Claude Desktop 的配置片段和 Claude Code 的一行命令。

原来仓库中的 Python 版 `mcp-server/` 已标记为弃用。详见 [MCP 集成](../03-features/08-mcp.md#供外部客户端调用)。

## 对话控制 {#conversation-control}

<Screenshot
  src="/screenshots/chat-steer-queue.png"
  caption="回答进行中，输入框上方排队等待的补充要求" />

- **中途补充要求**：智能体还在执行时就可以继续输入。按 Enter 排队，当前步骤结束后处理；按 ⌘Enter / Alt+Enter 立即插入当前任务。
- **分叉与回滚**：可以从任意一次历史提问分叉出新对话，也可以原地回滚到某次提问；使用沙箱的对话会同时恢复对应时刻的工作区。
- **思考强度**：每个对话可以单独选择模型的思考强度。
- **截断提示**：回答因达到输出上限被截断时会明确标出，不再悄悄截断。

## 沙箱：图形桌面、交互终端与本机沙箱 {#sandbox}

对话右侧的「沙箱可视化」面板新增「桌面」和「终端」两个页签，可以直接进入智能体正在使用的同一个沙箱。

<Screenshot

- **交互终端**：Cube 和 E2B 沙箱可用，刷新页面后可以重新接上仍在运行的终端。
- 打开面板不会创建或唤醒沙箱；长时间无操作会自动断开，默认 900 秒。
- 智能体执行命令、安装技能时，工具卡片会实时显示输出。

**Lite 桌面版本机沙箱（macOS）**：没有选择远程沙箱的对话，会在系统沙箱中执行命令。新对话可以绑定电脑上的一个项目文件夹，智能体只能写入这个文件夹；命令不能联网，`.git` 目录只读，凭据目录始终不可访问。

**工具箱**：技能、MCP 服务和浏览器连接从「设置」移到侧栏的「工具箱」，旧的设置入口会自动跳转。

## 模型接入 {#models}

模型接入改为按「协议、厂商、模型目录」三层组织，内置 27 个厂商。添加模型时：

- 从厂商目录中选择模型后，会自动填入上下文窗口、最大输出、思考强度和视觉能力。
- 「实际调用方式」面板直接显示这个模型将使用的请求协议、请求地址和可选的思考强度。
- 个别接口与默认值不一致时，可以在高级选项中覆盖协议，或填写协议兼容 JSON。
- 语音识别覆盖所有在文档中提供该能力的厂商。

## 知识库与数据源 {#knowledge}

- **Confluence 数据源**：支持 Cloud 和 Server / Data Center，按空间同步已发布页面，增量更新，并带删除保护。
- **钉钉文档数据源**；腾讯 IMA 同步时会遍历子文件夹。
- **上传与解析**：上传面板显示整体进度，可以取消、重试；解析时间线展示各阶段耗时和失败原因；长时间没有进展的文档会标记为「排队中」或「疑似卡住」。
- **列表与下载**：文档和资源列表支持排序；可以批量打包下载原始文件。
- **其他**：上传时可以关闭文档摘要；知识库描述可以根据文档画像自动生成；FAQ 可以按启用状态筛选；活动记录会显示操作所用的 API Key 名称。

## 集成、界面与安全 {#platform}

- **联网搜索**：新增博查和 Serply；Brave 与 Serply 支持按地区和时效过滤。
- **IM**：每个渠道可以单独设置回复语言。
- **日语界面**：界面新增日语，可在界面中切换，也可以用 `DEFAULT_LOCALE` 设为默认。
- **CLI 配置页**：「设置 → 发布集成 → CLI」按三步引导完成安装和登录。
- **管理员创建用户**：系统管理员可以在控制台直接创建账号，生成一次性密码并复制账号信息。
- **仅白名单出站**：设置 `SSRF_DNS_WHITELIST_ONLY=true` 后，不在 `SSRF_WHITELIST` 中的域名在 DNS 解析之前就会被拒绝，适合离线或严格管控的私有化部署。

## 升级须知 {#upgrade-notes}

| 变化 | 需要做什么 |
| --- | --- |
| `.env.example` 不再提供 `JWT_SECRET`、`SYSTEM_AES_KEY` 的默认值，并新增 `SYSTEM_SIGNING_KEY` | 新部署需要自行生成。**已有部署必须保留原来的 `SYSTEM_AES_KEY`**，否则已保存的凭据无法解密。未设置 `JWT_SECRET` 时每个进程会随机生成，重启后登录失效，多副本之间也无法共用 |
| 钉钉 IM 渠道只支持 Stream 模式 | 迁移 `000096` 会把 webhook 渠道自动改为 Stream；需要在钉钉开发者后台为应用开启 Stream 模式 |
| 沙箱内命令默认以 `root` 执行（v0.8.0 为 uid 1000） | 每个对话独占一个沙箱，隔离边界仍是容器；依赖普通用户身份的脚本需要自行调整 |
| 更新 MCP 服务时如果传了 `usage_instructions`，必须是非空文本且不超过 16000 字符 | 不传该字段则保留原有说明 |
| 组织邀请只能按工作空间 ID 精确查找 | 不再支持按名称搜索工作空间 |
| Go SDK 的 `UpdateAgentRequest.Avatar` 改为 `*string` | `nil` 表示保留头像，空字符串表示清除 |

数据库迁移：PostgreSQL 为 `000091`–`000110`，SQLite 为 `000013`–`000030`。其中 `000106` 以 `CONCURRENTLY` 方式创建索引，如果中途中断，需要先删除无效索引再重新执行迁移，参见[常见问题与升级排障](../01-getting-started/05-troubleshooting.md)。ParadeDB 镜像已升级，可以运行在不支持 AVX2 的 CPU 上；MinIO 镜像改为从 `quay.io` 拉取。

## 其他改进与修复 {#other-changes}

- **智能体**：检索工具合并为 `search_knowledge`、`read_document`、`list_documents`，旧工具名自动映射，无需迁移配置；对话历史按模型上下文窗口裁剪，压缩检查点跨轮保留；MCP 工具改为按需发现和调用，服务的工具目录会持久保存，并可以单独启用或停用某个工具。
- **技能**：旧版本技能升级时不再回滚目录，也不会中途下线；安装后会校验运行时依赖。
- **Wiki**：整页重写被截断时会续写；同名条目跨类型复用页面；引用的分块会附带图片说明。
- **检索与解析**：Milvus 支持多语言 BM25；Neo4j 查询增加上限保护；PaddleOCR-VL 请求超时可配置；PDF 在链接 anydoc 时仍默认使用内置解析器；内联 HTML 表格不再产生超长分块。
- **稳定性**：修复文档卡在「处理中」或「删除中」的多种情况；关闭共享空间中跨工作区访问的路径；已删除租户的 Wiki 任务不再调用模型；向量、重排和部分对话厂商的请求格式已与其官方文档对齐。

完整列表见 [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md)。
