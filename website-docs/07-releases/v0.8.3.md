# v0.8.3 版本说明

发布日期：2026-10-14

v0.8.3 让文档中的图片更容易找到和使用：在画廊中浏览图片与图表，通过多模态 Embedding 用文字检索图片内容。回答引用可以直接定位原文，智能体可以按需阅读会话附件。Wiki 图谱改进分组布局与浏览方式，方便从整体关系聚焦到具体主题；此外还新增平台用户管理、模型目录管理和 Seafile 数据源，并改进解析、检索与同步的稳定性。

从 v0.8.2 升级前，请先阅读[升级须知](#upgrade-notes)。完整的变更列表见 [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md)。

## 画廊 {#images}

文档知识库新增「画廊」页签，将文档中的图片集中展示。查找图表、截图或照片时，可以先浏览图片，再打开来源文档核对。

<Screenshot src="/screenshots/kb-image-gallery.png" caption="画廊：浏览文档图片，按来源筛选" hint="展示多份文档的图表和照片、画廊页签与来源文档多选弹层，隐藏敏感资料。" />

<Screenshot src="/screenshots/kb-image-gallery-detail.png" caption="画廊详情：查看原图、图片描述、识别文字与来源文档" />

- **搜索与筛选**：搜索图片描述和 OCR 文字，按图片属性筛选，也可以同时选择多份来源文档。
- **查看图片详情**：放大查看原图，同时阅读描述、识别文字与来源信息。
- **使用已有图片**：画廊展示文档解析时提取的图片，无需开启图片向量检索。

详见[知识库画廊](../03-features/02-knowledge-base.md#image-gallery)。

## 多模态 Embedding {#multimodal-embedding}

支持多模态 Embedding 模型，让文字与图片共同参与检索。用文字提问时，可以找到内容相关的图表、截图或照片，补充图片描述和 OCR 容易遗漏的信息。

腾讯 WeMM-Embedding、Qwen3-VL-Embedding 等是已支持的模型示例。本次新增腾讯 WeMM-Embedding 2B、4B、9B 预设，并提供 Transformers 部署脚本，也可接入 vLLM 服务。

<Screenshot src="/screenshots/kb-image-vector-settings.png" caption="在知识库图像处理中开启图片向量检索" hint="展示向量模型、多模态处理与图片向量开关；可用腾讯 WeMM-Embedding 作为配置示例。" />

命中的图片还可以交给支持图片输入的重排模型评估相关性，并传给视觉对话模型用于回答。

图片向量检索默认关闭。使用前需配置支持图片输入的向量模型，开启知识库多模态处理和图片向量检索；已有文档需重新解析。扫描 PDF 的整页图片不生成图片向量，仍通过 OCR 文本参与检索。模型接入与完整条件见[多模态 Embedding 配置](../03-features/02-knowledge-base.md#multimodal-embedding)、[WeMM 模型接入](../03-features/06-models.md#wemm-embedding)和 [Transformers 部署](../06-development/06-wemm-transformers.md)。

## 原文引用与会话附件 {#conversation}

拥有原文件访问权限时，点击回答中的知识库引用，可以直接打开 PDF、Office、Markdown、TXT、EPUB 等原文件，定位并高亮相关片段。带分段时间的音频引用可以跳到对应位置播放，核对回答更方便。手动录入、FAQ 等没有原文件的内容，以及嵌入聊天的访客，仍通过引用列表查看来源。

<Screenshot src="/screenshots/chat-source-location.png" caption="从回答引用跳到原文，查看对应段落" hint="一侧展示带引用回答，另一侧打开 PDF 或 Office 原文件，显示对应段落高亮与返回全部引用入口。" />

智能体可以先查看附件清单，再按需要分页阅读正文、查看文档中的图片，无需配置沙箱。已发送的附件只要仍被原会话或分叉会话引用，就会保留，后续提问可以继续使用。

<Screenshot src="/screenshots/chat-attachment-read.png" caption="智能体按需阅读附件正文与文档内图片" hint="展示含图 PDF 的附件卡片、正文阅读及图片观察结果。" />

### 用 `@` 选择与搜索资源

点击输入框中的 `@` 按钮，或直接输入 `@`，即可打开资源选择菜单，按知识库、标签、技能、文件等类别浏览并选择资源。菜单显示各类别的资源数量，也支持直接搜索多个类别中的资源，或进入某一类别继续筛选，方便在提问时指定要使用的资料与能力。可选资源受当前智能体的配置与访问权限限制。

<Screenshot src="/screenshots/chat-mention-selector.png" caption="会话中的 @ 资源选择菜单：按类别浏览知识库、标签、技能与文件，并搜索所需资源" />

会话还新增未读回答标记，改进回滚确认与 Markdown 编辑体验；嵌入聊天支持粘贴截图和只发送图片。详见[会话体验](../03-features/18-chat-experience.md)。

## Wiki 图谱：从整体关系到分组浏览 {#wiki-graph}

Wiki 图谱重新组织了页面关系的展示方式。关联页面分组布局，并显示能概括组内内容的主题说明；节点与标题减少重叠，浏览较大的图谱时更容易找到关注的内容。

<Screenshot src="/screenshots/wiki-graph-groups.png" caption="Wiki 图谱：分组布局、主题说明与聚焦浏览" hint="展示多个关联页面分组及主题说明；可补充分组聚焦状态，包含分组切换和「返回全图」入口。" />

- **先看整体**：在分组轮廓和主题说明中辨认主要内容，沿连线查看页面之间的关联。
- **聚焦一组页面**：点击分组主题进入聚焦视图，可切换其他分组；通过「返回全图」或 Esc 回到整体。
- **减少干扰**：标题会避让重叠，可隐藏无关联页面，继续配合搜索与页面类型筛选查找内容。
- **追溯来源**：页面与其来源文档的摘要页建立连接，便于理解条目来自哪些资料。

此外，Wiki 搜索 API 支持跨多个有权限的知识库查询；页面维护改进了表格保留、反向链接标题展示和后台生成任务的处理。这里展示的是 Wiki 页面间的链接关系。详见[Wiki 图谱浏览](../03-features/14-wiki.md#wiki-graph)。

## 平台用户与模型管理 {#administration}

系统管理员可在「设置 → 系统设置 → 用户管理」集中创建账号、启用或停用用户、重置密码和管理系统管理员身份。停用账号会吊销已有登录会话；不能停用自己或最后一位启用的系统管理员。

<Screenshot src="/screenshots/system-user-management.png" caption="平台用户管理：查看账号状态并管理用户" hint="展示用户列表、账号状态、管理员标记与操作菜单；使用演示邮箱，不展示密码。" />

注册策略新增「仅限邀请注册」，可让新成员凭邀请创建账号。原有的「禁止注册」模式不再接受邀请注册，升级时需要核对配置，见[升级须知](#upgrade-notes)。

模型目录控制台支持编辑模型目录、预览并发布配置，以及查看历史和恢复旧配置。内置厂商增至 30 个，新增 Hugging Face TEI、Pinecone 和 Cohere 重排接入，并补充模型预设与能力信息。

<Screenshot src="/screenshots/system-model-catalog.png" caption="模型目录：查看模型能力、来源与编辑入口" hint="展示厂商与模型列表、来源标记，以及覆盖编辑或版本历史面板。" />

详见[平台管理](../03-features/20-platform-admin.md)与[模型管理](../03-features/06-models.md)。

## 工具、MCP 与沙箱 {#tools}

- **Docker 交互终端**：Docker 沙箱也能在对话旁打开终端，查看文件和执行命令。断开后当前 Shell 结束，重连会打开新的 Shell。
- **Lite 本机技能**：macOS 桌面版可在本机安装和运行技能，更新失败时保留仍可用的旧版本。
- **工具选择**：智能体编辑器按知识库能力展示可选工具，可以明确选择不使用内置工具；技能和 MCP 服务列表新增搜索。
- **共享智能体与本机浏览器**：通过共享空间使用智能体时，可连接并操作调用者自己的本机浏览器。
- **MCP 授权**：人工审批通过后，可以继续完成服务所需的 OAuth 授权；支持预注册客户端，以及上游支持时的无浏览器授权方式。
- **MCP 兼容性**：改进协议协商、会话重连与结果传递，减少授权或慢连接清理对其他调用者的影响。

详见[技能和沙箱](../03-features/22-skills-sandbox.md)、[Agent](../03-features/07-agent.md)与 [MCP](../03-features/08-mcp.md)。

## 数据源 {#knowledge}

- **Seafile**：同步同一个未加密资料库中选定的目录和文件，保留目录结构，支持增量同步与可选的删除同步；暂不支持 SeaDoc 在线文档。
- **Confluence 与语雀**：同步时保留目录层级；Confluence 同时支持私有图片资源。
- **钉钉文档**：可导入上传到钉盘的 Office、PDF 文件，改进文档内容读取和部分工作区无权访问时的提示。

详见[数据源](../03-features/10-datasource.md)、[Seafile](../03-features/25-seafile.md)。

## 其他改进与修复 {#other-changes}

- **解析**：AnyDoc 升至 0.2.4，支持自建 MinerU 4.0 V1 API；修复 EPUB 章节和图片、PPTX 图片关联、异常 Excel 文件及 Markdown 表格的解析问题。
- **图片处理**：可根据观察到的图片属性决定是否执行 OCR；异常重复、空白或被截断的 OCR 结果不再作为有效内容入库，失败原因可在处理轨迹中查看。
- **检索**：知识搜索 API 与问答统一重排行为，支持配置检索阈值、检索方式和重排参数，并返回诊断信息；改进结果排序、索引复制和批量写入。
- **知识图谱**：修复实体关系方向与来源文档信息，明确提示图谱查询结果的截断范围，避免将部分结果当成全部内容。
- **访问与管理**：修复共享知识库的数据分析权限问题；空间管理员可管理渠道会话，登录凭证保存失败时不再返回登录成功。
- **同步**：改进 Notion、语雀、IMA、飞书、GitLab 与 RSS 的分页、下载及失败重试，避免来源内容清空后仍能搜到旧正文。
- **智能体与会话**：修复排队追问的回答归属、追加顺序及上下文压缩问题，改进模型调用超时与重试处理。
- **IM、CLI 与 SDK**：改进企业微信图文消息、飞书图片和云之家附件处理；CLI 递归上传保留目录，修复列表分页与输出问题；Go SDK 改进流式响应和上传重试；智能体完成事件返回该轮实际使用的对话模型 ID，便于调用方识别模型回退。
- **部署与界面**：ParadeDB 更新到 `v0.25.11-pg17`，完善 Helm 部署配置；界面新增繁体中文，统一设置、列表、工具箱与引用样式。

## 升级须知 {#upgrade-notes}

先备份数据库、文件存储和配置，再按[安装部署](../01-getting-started/02-installation.md)更新。保留原有 `SYSTEM_AES_KEY`、JWT 与签名密钥。早于 v0.8.2 的部署还需阅读 [v0.8.2 升级说明](v0.8.2.md#upgrade-notes)。

| 变化 | 升级操作 |
| --- | --- |
| PostgreSQL `000111`–`000118`、SQLite `000031`–`000036` | 留出迁移时间。`000113` 回填画廊投影；`000112` 普通创建 embeddings 索引，大表可提前同名 `CREATE INDEX CONCURRENTLY`，详见[数据库与迁移](../06-development/02-database-schema.md) |
| ParadeDB / 扩展升级 | 先核对并切换配套镜像，再执行迁移。`000115` 对适用的旧扩展升级至 pg_search 0.25.11 / vector 0.8.4；镜像与扩展不匹配可能导致数据库错误，**不要在新镜像执行旧的 0.22.6 升级命令**，参见[存量库升级](../01-getting-started/06-paradedb-upgrade.md) |
| `invite_only` 不再允许邀请注册 | 需要受邀新用户自行注册时，将运行时 `auth.registration_mode` 改为 `invite_register`；`DISABLE_REGISTRATION=true` 仍对应禁止注册 |
| `allowed_tools: []` 不再表示默认工具 | 旧智能推理 Agent 由迁移写入原默认工具；新 API 请求若需要默认工具应省略或传 null。迁移后的显式默认检索工具会按其能力过滤「全部知识库」范围，检查依赖仅 Wiki 知识库的旧 Agent |
| 图片向量默认关闭 | 按需启用支持图片输入的向量模型、多模态和知识库开关，再重新解析目标文档。改用 Qwen3-VL-Embedding / WeMM 的 messages 编码配置后，旧文本 input 建立的向量需要重建 |
| 原文引用位置 | 旧文档可先用文字回退匹配；需要精确页码/段落定位时重新解析 |
| MCP OAuth 时间戳 | 迁移将旧值按 UTC 转为带时区字段；曾在非 UTC 进程写入的偏移值需重新授权或刷新 token 才能纠正 |
| 已发送附件保留时间变长 | 有有效会话引用就会保留，存储用量随会话历史累积；未引用附件仍按 TTL 清理 |
| Docker 终端断开 | 当前 Shell 会结束，重连是新 Shell；需要继续运行的后台任务应自行使用合适的进程管理方式 |
