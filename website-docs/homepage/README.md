# WeKnora homepage source

The Next.js homepage is one part of the unified site. Run `npm run setup`, `npm run build`, and `npm run preview` from the parent directory to include both the homepage and the complete `/docs/` site. Deployment instructions are in the parent README.

- `app/page.tsx`: product content and same-origin documentation links.
- `app/home.module.css`: homepage layout.
- `app/interactive.tsx`: responsive navigation, theme switch, and on-demand README video.
- `app/adopters.ts`: the sixteen teams/products from the supplied brand packs, with use cases, public links, and adoption stages where explicitly reported. `variant: "A"` centers a horizontal logo alone; `variant: "B"` places a square logo beside the company/product name. `logoSize` records the source dimensions; optional `logoScale` trims excessive blank canvas in the display without changing the artwork. 赛乐医疗 uses A and 智达创客 uses B, correcting their reversed original-pack settings. The eight additions from `合作素材_20261119.zip` follow the original eight brands and use that pack's A/B settings. Honor the supplied roster; do not add other issue submissions to the display. Original logos live in `public/docs/_home/adopters/`. Sources are recorded in `BRAND-ASSETS.md`.
- `app/adopter-showcase.tsx`, `app/adopters.module.css`: a compact logo strip below the hero. Logo cards fit the logo proportions and company name, with centered content and no name wrapping. They keep a white surface and dark company names in both themes, while the section and hover details follow the site theme. Two equal-width copies form a continuous linear CSS loop; its duration scales with the roster at 7.5 seconds per brand to maintain a similar scrolling pace. Hovering the logos pauses the strip and reveals a floating detail panel, while touch users tap a logo. The heading and contribution link do not pause motion. Details close on pointer exit, outside tap, or Escape, without pause or close buttons. Cards show the brand name, industry and use-case tags, then a short description. Brands with a public URL have an external-link icon beside the detail title that opens in a new tab. Adoption stages remain curated metadata; submission sources remain in `BRAND-ASSETS.md`. Keyboard and reduced-motion users get one stationary, horizontally scrollable row. Duplicate logos are excluded from the tab order and accessibility tree; details sit outside the clipped strip.
- `app/theme.ts`: VitePress-compatible theme persistence and pre-paint initialization.
- `../shared/brand.css`: shared light/dark design tokens.
- `public/docs/_home/`: homepage images. The site serves only `/` and `/docs/`, so build output and public assets both live under `/docs/_home/` (`homeAssets` in `../shared/header.ts`).

`npm run dev` can still preview the homepage alone during development. `/docs/` requires the combined preview from the parent directory.
