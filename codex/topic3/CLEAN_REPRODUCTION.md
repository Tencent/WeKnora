# 空数据库最低费用复现说明

本步骤只在代码推送到用户 Fork、固定 Commit SHA 后执行。现在不要执行。

## 隔离原则

- 新检出目录、新 Compose 项目名、新数据库卷、新缓存卷。
- 原环境只执行不删除卷的停止操作；禁止对原环境执行 `down -v`。
- 新环境只跑1题评测和1次 Wiki 前缀校准，不重复10题、9轮缓存或8次 Wiki 实验。
- Key 只由用户在界面和隐藏终端提示中输入。

## 用户只需完成的操作

1. 在新环境首次登录。
2. 配置对话、Embedding、ReRank 三个模型。
3. 创建仅允许1题知识库和评测权限的本地 API Key。
4. 在复现命令的隐藏提示中粘贴本地 Key 一次。

## 自动验收项目

- 五个容器状态和迁移83、`dirty=false`。
- 全部确定性专项测试。
- 1题数据导入、索引等待和1/1真实评测。
- 质量、用量、耗时和数据库持久化。
- app重启后评测历史仍可查询。
- 一次固定 Wiki 前缀 Token 校准。
- Docker版本、Commit SHA、配置摘要、结果及日志哈希。
- 结束后恢复原 WeKnora，确认正式批次仍完整。

## 完成证据

复现报告必须明确记录：新环境不复用旧数据库或缓存、1题评测成功、重启后数据存在、固定Commit SHA、所有输出无 Key。固定前缀不足1024 Token时只修正校准方法和说明，不重跑已经冻结的正式实验。
