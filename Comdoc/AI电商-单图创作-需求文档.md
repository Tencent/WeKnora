# 单图创作 - 需求文档

> 基于 Figma 设计稿（以设计稿为准）+ PRD 补充

---

## 一、功能概述

单图创作是 AI 电商产品图平台的核心创作功能之一。用户通过输入文本描述、上传素材图和模板图、关联商品信息，由 AI 自动生成符合电商平台规范的商品图片。

**与套图创作的区别：**
- 单图创作：一次生成**一张**图片，灵活度高，适合快速试验效果、反复调整
- 套图创作：按模板规则批量生成一整套商品图（主图+详情页+SKU图），适合批量产出

**关键限定：**
- 单图创作结果**不进入成品中心**，只有套图创作的结果才进入成品中心
- 单图创作和套图创作的任务都统一收入**创作记录**

---

## 二、页面布局

页面分为左右两栏：

- **左侧 - 创作配置区**：文本描述输入、素材图/模板图上传、关联商品、图片参数设置、生成按钮
- **右侧 - 结果展示区**：两个Tab（执行记录 / 历史图片），展示生成结果，支持选择、下载

---

## 三、功能说明

### 3.1 文本描述

**功能：** 用户输入想要生成的图片描述（prompt），描述越详细生成效果越好。

**规则：**
- 必填项，不能为空
- 最多 1000 个字符
- 输入框下方提供示例引导文案：_"请输入您想要生成的图片描述，例如：一位穿着时尚连衣裙的年轻女性，站在都市街头，背景是繁华的商圈..."_

---

### 3.2 素材图

**功能：** 用户上传参考图片，AI 会参考这些图片的风格、构图、商品细节来生成新图片。

**规则：**
- 用户自行上传，非从系统其他模块获取
- 最多上传 **10 张**
- 支持格式：jpg、jpeg、png、webp
- 单张不超过 10MB
- 上传后显示缩略图预览，带序号标记（1、2、3...）
- 每张图片右上角有删除按钮（×），可移除

---

### 3.3 模板图

**功能：** 用户上传模板图片，作为生成图片的构图和排版参考。

**规则：**
- 用户自行上传
- 最多上传 **1 张**
- 格式和大小限制同素材图
- 上传后显示缩略图预览，可删除替换

---

### 3.4 关联商品

**功能：** 用户选择已录入的商品，选择商品的颜色和图片。对后端来说，**关联商品的核心目的就是获取参考图的URL**，与用户自行上传素材图的作用一致——都是为AI提供参考图片。

**操作流程：**
1. 用户点击"关联商品"按钮
2. 弹出商品选择弹窗
3. 弹窗内可搜索（商品名称、品牌、品类、材质）
4. 商品列表展示：商品名称、品牌、细分品类、商品颜色（带复选框）、对应颜色的商品图片（带复选框）、商品编码、材质面料
5. 用户勾选商品及其颜色和图片
6. 点击"确定"，关联信息显示在创作配置区
7. 关联商品名称以链接形式展示，点击可查看商品详情

**规则：**
- 最多关联 **1 个**商品
- 可选择该商品的多个颜色和多张图片
- 关联后可取消关联（点击×移除）
- 关联商品弹窗的数据来源于**商品管理**模块

---

### 3.5 AI润色

**功能：** 对用户输入的文本描述进行 AI 优化，补充专业摄影术语、构图描述、光影描述等，提升生成图片质量。

**操作流程：**
1. 用户先输入文本描述
2. 点击"AI润色"按钮
3. 系统调用AI对描述进行优化，实时流式展示润色结果
4. 润色完成后替换原始描述（用户仍可手动修改）

**规则：**
- AI润色**不消耗积分**
- 如果已关联商品，润色时会结合商品信息（品牌、材质、卖点）进行优化
- 润色过程中按钮状态变为"润色中..."，不可重复点击
- 文本描述为空时，AI润色按钮置灰不可用

---

### 3.6 图片设置

#### 3.6.1 分辨率

| 选项 | 尺寸 | 说明 |
|------|------|------|
| 1K | 1024 × 1024 | 默认选项，适合日常使用 |
| 2K | 2048 × 2048 | 高清 |
| 4K | 4096 × 4096 | 超高清，适合大图展示 |

#### 3.6.2 图片比例

可选比例：**1:1**、**4:3**、**3:4**、**16:9**、**9:16**

默认比例：**3:4**（设计稿默认值）

> 分辨率指的是基础尺寸，实际输出尺寸根据比例计算。例如 1K + 3:4 = 1024 × 768（待确认具体计算逻辑）。

---

### 3.7 生成图片

**功能：** 提交所有配置参数，触发 AI 生成图片。

**操作流程：**
1. 用户点击"生成图片 10🔥"按钮
2. 系统校验积分余额是否充足（≥ 10）
3. 校验通过：扣减 10 积分，创建生成任务，按钮状态变为"生成中..."
4. 校验失败：提示"积分不足"
5. 生成为异步任务，右侧结果区展示任务进度
6. 生成完成后，右侧展示生成的图片

**规则：**
- 每次生成 **1 张** 图片
- 消耗 **10 积分**
- 文本描述为空时，生成按钮置灰不可用
- 生成过程中用户可以继续修改左侧配置（为下一次生成做准备），不影响当前生成任务
- 生成失败时**退回积分**

---

### 3.8 生成结果展示（右侧区域）

#### 3.8.1 执行记录 Tab

按时间倒序展示**当前用户**在单图创作中的所有任务记录。

**每条记录展示：**
- 生成日期和时间
- 任务状态（执行中/已完成/失败）
- 生成的图片缩略图

**图片操作：**
- 单击图片：勾选/取消勾选
- 勾选后可操作：批量下载
- 每张图片右上角：单独下载按钮
- hover某张图片：出现下载按钮
- 批量下载：下载所有选中的图片（多次生成的结果可跨批次勾选下载）

#### 3.8.2 历史图片 Tab

仅展示**已完成**的任务结果图片（不含执行中和失败的），其他交互同执行记录Tab。

#### 3.8.3 图片放大查看

- 点击图片可打开灯箱模式
- 灯箱内展示大图，左右箭头切换同批次内的其他图片
- 右上角关闭按钮

## 四、创作记录（跨模块页面）

> 创作记录是独立页面（左侧导航"创作记录"入口），聚合展示**单图创作和套图创作**的所有任务。此处与单图创作关系密切，因此在本文档中一并说明。

### 4.1 页面布局

**顶部Tab：** 全部 | 执行中 | 已完成 | 失败

**搜索条件栏：** 日期（日期选择器）、创作类型（下拉：单图创作/套图创作）、品牌（下拉选择）、商品名称（输入框）、模板名称（输入框）、查询按钮

**列表字段：**

| 列名 | 说明 |
|------|------|
| 创作类型 | 单图创作 / 套图创作 |
| 创作图片 | 缩略图（已完成显示生成结果首图，执行中/失败显示素材首图） |
| 品牌 | 彩色标签展示品牌名（如 都市丽人-蓝色标签、韩美美-橙色标签） |
| 商品名称 | 关联商品名称，未关联则为空 |
| 模板名称 | 套图创作必有模板名；单图创作未使用模板则显示"---" |
| 创作人 | 操作用户名 |
| 创作时间 | 格式：yyyy-MM-dd HH:mm:ss |
| 状态 | 已完成（绿色）/ 执行中（橙色）/ 失败（红色） |
| 操作 | 返回任务 |

**分页：** 底部分页控件

### 4.2 "返回任务"功能

**功能：** 用户点击"返回任务"后，跳转回对应的创作页面，恢复该任务的完整创作上下文。

**不同状态下的行为：**

| 任务状态 | 跳转后的页面表现 |
|----------|----------------|
| **执行中** | 跳转到创作页面，左侧恢复所有配置参数，右侧显示加载进度，等待生成完成 |
| **已完成** | 跳转到创作页面，左侧恢复所有配置参数，右侧展示生成结果，可下载图片 |
| **失败** | 跳转到创作页面，左侧恢复所有配置参数（用户可修改后重新提交），右侧显示失败提示 |

**恢复的上下文内容：**
- 文本描述（原始prompt）
- 素材图（预览+排序）
- 模板图
- 关联商品信息
- 分辨率和图片比例设置
- 生成结果（如果有）

**路由规则：**
- 创作类型为"单图创作" → 跳转到单图创作页面
- 创作类型为"套图创作" → 跳转到套图创作页面

## 五、状态流转

### 5.1 生成任务状态

```
  ┌──────┐    提交任务     ┌──────┐    开始生成    ┌──────┐
  │      │ ──────────────▶ │      │ ────────────▶ │      │
  │ (无)  │                │ 待执行 │               │ 执行中 │
  │      │                │      │               │      │
  └──────┘                └──────┘               └───┬──┘
                                                     │
                                          ┌──────────┴──────────┐
                                          ▼                     ▼
                                     ┌──────┐             ┌──────┐
                                     │      │             │      │
                                     │ 已完成 │             │ 失败  │
                                     │      │             │      │
                                     └──────┘             └──────┘
```

| 状态 | 触发条件 | 说明 |
|------|----------|------|
| 待执行 | 用户提交生成任务 | 任务已创建，等待系统处理 |
| 执行中 | 系统开始调用AI生图 | AI正在生成中 |
| 已完成 | AI生成成功，图片已保存 | 用户可查看/下载结果 |
| 失败 | AI生成出错或超时 | 显示失败原因，用户可通过"返回任务"重新提交 |

### 5.2 积分变化

| 时机 | 积分变化 | 说明 |
|------|----------|------|
| 提交任务 | -10 | 立即扣减 |
| 生成成功 | 无变化 | — |
| 生成失败 | +10 | 退回已扣减的积分 |

## 六、业务规则汇总

### 6.1 生成规则

| 规则项 | 规则说明 |
|--------|---------|
| 每次生成数量 | 1 张 |
| 积分消耗 | 10 积分/次 |
| 积分不足 | 拒绝提交，提示"积分不足" |
| 文本描述 | 必填，最多1000字 |
| 素材图 | 用户自行上传，最多10张，jpg/jpeg/png/webp，单张≤10MB |
| 模板图 | 用户自行上传，最多1张，格式同素材图 |
| 关联商品 | 最多1个商品，可选多个颜色和图片 |
| 分辨率 | 1K(默认)/2K/4K |
| 图片比例 | 1:1/4:3/3:4(默认)/16:9/9:16 |
| AI润色 | 不消耗积分，文本为空时不可用 |
| 并发限制 | 不限制，同一用户可同时发起多个生成任务 |

### 6.2 AI生成逻辑

AI生成图片时，系统会综合以下信息作为输入：

1. **文本描述**：用户输入的描述（或AI润色后的版本）
2. **参考图片**：包括用户上传的素材图 + 模板图 + 关联商品选中的商品图片，对后端来说这些本质上都是**参考图URL列表**

以上信息由系统整合后传给AI生图服务。

### 6.3 创作记录规则

| 规则项 | 规则说明 |
|--------|---------|
| 数据来源 | 单图创作 + 套图创作的所有任务 |
| 排序 | 按创建时间倒序 |
| Tab筛选 | 全部/执行中/已完成/失败，与搜索条件叠加 |
| 品牌标签颜色 | 不同品牌使用不同颜色标签（颜色由品牌配置决定） |
| 模板名称 | 单图创作未使用模板时显示"---" |
| 返回任务 | 所有状态的记录都可以"返回任务"，跳转后根据状态展示不同页面 |

## 七、异常场景

| 场景 | 处理方式 |
|------|----------|
| 积分不足时点击生成 | 提示"积分不足，当前余额XX，本次需要10积分"，不创建任务 |
| 未填写文本描述 | 生成按钮置灰，不可点击 |
| 上传素材图超过10张 | 提示"素材图最多上传10张"，拒绝上传 |
| 上传图片格式不支持 | 提示"仅支持jpg、jpeg、png、webp格式" |
| 上传图片超过10MB | 提示"图片大小不能超过10MB" |
| AI生成超时 | 任务标记为失败，失败原因"生成超时"，退回10积分 |
| AI生成异常 | 任务标记为失败，记录具体失败原因，退回10积分 |
| 生成过程中关闭/离开页面 | 任务继续执行，用户可通过"创作记录→返回任务"查看结果 |
| AI润色过程中关闭/离开 | 润色中断，不影响已有描述 |

## 八、与其他模块的关系

| 关联模块 | 关系说明 |
|----------|---------|
| **商品管理** | 单图创作通过"关联商品"获取商品数据（品牌、材质、卖点等），辅助AI生成更贴合商品的图片 |
| **创作记录** | 每次单图创作任务都记入创作记录，用户可在创作记录中查看历史、通过"返回任务"恢复创作上下文 |
| **积分体系** | 每次生成消耗10积分，页面右上角实时显示积分余额 |
| **成品中心** | **无直接关系**。单图创作结果不进入成品中心，只有套图创作结果才进入 |

## 九、已确认事项

| 序号 | 问题 | 结论 |
|------|------|------|
| 1 | 生成失败时积分是否退回？ | **退回**，失败后自动退回10积分 |
| 2 | 同一用户是否可以同时发起多个生成任务？ | **不限制**，可同时发起多个任务 |
| 3 | 积分消耗是否固定？ | **固定10积分/次**，不因分辨率变化 |
| 4 | "修改图片"按钮 | 设计稿中**未找到该按钮**，本期不涉及 |
| 5 | "再次对话"功能 | **本期不做**，后续版本再考虑 |
| 6 | 历史图片是否有过期策略？ | **永久保留**，不设过期 |
| 7 | 分辨率+比例的输出尺寸计算 | 正常传参给AI服务即可，不需要额外计算 |
| 8 | 积分充值/购买入口 | **现有项目已有**充值功能，不需要本期开发 |
| 9 | 关联商品的本质 | 对后端来说，关联商品 = **获取商品参考图URL**，与用户上传素材图本质一致 |

## 十、验收标准

### 10.1 单图创作

- [ ] 用户可输入文本描述，支持最多1000字符
- [ ] 用户可上传素材图（最多10张）和模板图（最多1张）
- [ ] 用户可关联1个商品，关联后展示商品信息
- [ ] AI润色功能可正常优化文本描述，不消耗积分
- [ ] 点击生成后正确扣减10积分，积分不足时给出提示
- [ ] 异步生成任务正常执行，生成1张图片
- [ ] 右侧执行记录/历史图片正确展示生成结果
- [ ] 图片支持单张下载和批量下载
- [ ] 图片可点击放大，灯箱模式支持左右切换
- [ ] 生成失败时积分正确退回
- [ ] 同一用户可同时发起多个生成任务，互不影响

### 10.2 创作记录

- [ ] 列表正确聚合展示单图创作和套图创作的任务
- [ ] Tab筛选（全部/执行中/已完成/失败）正常工作
- [ ] 多条件搜索（日期/类型/品牌/商品/模板）正常工作
- [ ] 品牌以彩色标签正确展示
- [ ] "返回任务"可正确跳转到对应创作页面，恢复完整上下文
- [ ] 执行中/已完成/失败三种状态返回任务后，页面表现符合预期
