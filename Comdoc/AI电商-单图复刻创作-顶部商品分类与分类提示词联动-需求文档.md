# AI电商-单图复刻创作-顶部商品分类与分类提示词联动-需求文档

> 文档版本：1.0
> 创建时间：2026-05-12
> 基于现有页面、线上前端实际交互与当前后端代码现状整理
> 影响页面：
> - `http://192.168.2.104/eCommerceManagement/singleImageReplicaCreation`
> - 本次**不改** `http://192.168.2.104/eCommerceManagement/singleImageCreation`

## 一、需求概述

### 1.1 背景

当前单图复刻创作页面顶部已经增加了一排“商品分类”选项，用户可以先选择分类，再继续填写文案、上传商品图、上传参照图并提交复刻任务。

但按当前后端实现，单图复刻创作命中分类提示词的依据仍然还是“已选商品自身所属的分类”，而不是页面顶部用户手选的分类。

本次需求的目标是把这套逻辑改成：

```text
页面顶部用户选中的商品分类 -> 直接作为单图复刻创作的分类提示词命中依据
```

不再依赖“先选商品、再由系统反查商品分类”的旧方式。

### 1.2 需求范围

本次**只改单图复刻创作**，不改单图自由创作。

| 页面 | 是否改动 | 说明 |
|---|---|---|
| 单图复刻创作 | 是 | 顶部商品分类参与提示词命中和弹窗联动 |
| 单图自由创作 | 否 | 即使页面已有类似分类 UI，本版本也不修改其提交协议和后端行为 |
| 复刻提示词后台配置页 | 复用 | 继续使用现有复刻提示词后台配置体系，不新增新页面 |

### 1.3 核心目标

1. 单图复刻创作提交时，优先使用页面顶部用户最终选择的商品分类命中分类提示词
2. “上传商品图”弹窗打开时，顶部已选分类要参与商品查询条件
3. 如果用户没有先选顶部分类，但在弹窗中选择了已有商品，则商品所属分类要回填到顶部分类
4. 如果用户走本地上传商品图路径，则以顶部用户已选分类为准；如果顶部未选分类，则允许继续并走默认提示词前后缀
5. 返回任务时，需要恢复该次任务实际使用的顶部商品分类

补充说明：

- 顶部商品分类在单图复刻创作页面中**不是必选项**
- 用户未选择顶部商品分类时，仍然允许继续完成页面操作和提交任务
- 只有在存在顶部分类值时，才参与分类提示词命中和弹窗查询联动

## 二、当前现状

### 2.1 页面现状

通过实际访问页面可确认，单图复刻创作页顶部已经存在“商品分类”单选区，位置在创作区最上方，当前以胶囊按钮形式展示，例如：

- 测试
- 服装
- 皮带
- 鞋子
- 包箱
- 帽子
- 内裤
- 文胸

“上传商品图”按钮点击后，会打开“选择关联商品”弹窗。弹窗内已经同时具备两条路径：

1. 上传本地图片
2. 选择已有商品

弹窗查询区当前已有以下筛选项：

- 商品名称
- 商品货号
- 品牌
- 商品分类

### 2.2 顶部商品分类的数据来源现状

当前单图复刻创作页顶部商品分类，复用的是现有商城分类体系中的一批启用分类数据。

### 2.3 “二级分类”口径说明

虽然当前页面使用的是现有商城分类体系中的“level = 1”这一层数据，但在该体系之上还存在更上层的父级。

因此，对本需求而言：

- 页面顶部当前这批 `level = 1` 的分类，按业务口径视为“二级分类”
- 本文档中提到的“顶部商品分类”“二级分类”，指的就是页面当前这批可选分类

### 2.4 后端分类提示词命中现状

当前单图复刻创作的分类提示词命中逻辑如下：

1. 提交任务时，如果选择了已有商品，会基于该商品所属分类去命中复刻提示词
2. 如果分类提示词未配齐，则整体回退默认提示词前后缀

当前这套逻辑的核心问题是：

- 页面顶部用户显式选择了分类，但后端并不会直接用它
- 如果用户没有选择已有商品，只走本地上传商品图路径，当前后端也拿不到页面顶部用户真实选择的分类

## 三、目标方案

### 3.1 总体原则

单图复刻创作的分类提示词命中依据，改为：

```text
以前端页面顶部最终选择的“二级分类”为准
```

并且这个“二级分类”要贯穿以下链路：

1. 页面顶部选择
2. 上传商品图弹窗联动
3. 提交生成
4. 分类提示词命中
5. 返回任务恢复

### 3.2 不再使用的旧依据

本次需求落地后，单图复刻创作的分类提示词命中不再依赖“通过已选商品反查分类”这条旧路径。

注意：

- 已选商品仍然可以保留，用于已有商品选择、展示商品信息、带回商品图等现有能力
- 但在“提示词命中分类”这件事上，已选商品不再是唯一数据来源

## 四、详细业务规则

### 4.1 顶部商品分类展示规则

1. 单图复刻创作页面顶部继续展示“商品分类”区域
2. 当前版本继续复用现有商城分类数据来源
3. 页面只展示返回结果中的启用分类
4. 提交时以用户最终选中的顶部分类为准
5. 本次业务上把这批 `level = 1` 的分类视为“二级分类”
6. 顶部商品分类为**非必选项**

### 4.2 “上传商品图”弹窗联动规则

#### 场景一：用户已先选顶部商品分类，再点击“上传商品图”

当用户已经在页面顶部选中了某个商品分类后，点击“上传商品图”按钮：

1. 弹窗打开
2. 该顶部商品分类自动带入弹窗中的“商品分类”查询条件
3. 用户在弹窗中查看已有商品时，默认按这个分类筛选商品

这里的“带入查询条件”是本次需求的必需规则。

#### 场景二：用户未先选顶部商品分类，直接点击“上传商品图”并选择已有商品

如果用户打开弹窗前没有选择顶部商品分类，但在弹窗中选择了一条已存在的商品：

1. 用户确认选择已有商品
2. **仅当该商品所属分类存在于页面顶部商品分类可选项中时**，才将该分类回填到页面顶部商品分类区域
3. 如果该商品所属分类不在页面顶部商品分类可选项中，则不做回填，顶部商品分类继续保持为空
4. 后续提交任务时：
   - 如果已经成功回填顶部商品分类，则以这个回填后的顶部商品分类作为分类提示词命中依据
   - 如果未成功回填，且用户后续也没有手动选择顶部商品分类，则提交时走默认提示词前后缀

也就是说，在“选择已有商品”这条路径下，顶部商品分类允许由商品反向带回。

#### 场景三：用户走“上传本地图片”路径

如果用户在“上传商品图”弹窗中选择的是“上传本地图片”而不是已有商品：

1. 如果用户此前已经选中了顶部商品分类，则以后续页面顶部这个分类为准
2. 因为本地上传图片无法可靠反推出商品真实分类，所以不从图片内容反推分类
3. 此时后端直接使用页面顶部最终选择的分类命中分类提示词

#### 场景四：用户走“上传本地图片”路径，且顶部未选分类

如果用户选择本地上传图片，但页面顶部没有选择商品分类：

1. 允许继续上传和提交
2. 不强制补选分类
3. 生成时不命中分类提示词
4. 后端走现有默认提示词前后缀

### 4.3 提交生成时的分类优先级

单图复刻创作提交时，分类生效优先级如下：

1. **优先使用页面顶部最终状态中的商品分类**
2. 如果顶部最终没有分类，则走默认提示词前后缀

需要注意的是，场景二中“从已有商品反向带回顶部分类”完成后，本质上仍然是“顶部最终状态中的商品分类生效”。

### 4.4 分类提示词命中规则

当前复刻创作已有的提示词命中规则继续保留，只是分类来源从“已有商品反查分类”改为“页面顶部最终选择的商品分类”。

命中规则如下：

1. 如果存在顶部商品分类，则按该分类命中对应的分类提示词
2. 只有对应分类的前后缀都配置完整时，才使用该分类提示词
3. 如果顶部未选择商品分类，或者该分类提示词配置不完整，则整体回退默认提示词前后缀

仍然保留“前后缀原子兜底”原则：

- 不允许出现“分类前缀 + 默认后缀”
- 也不允许出现“默认前缀 + 分类后缀”

### 4.5 与现有后台配置的关系

本次不新增新的提示词配置页面，继续复用现有复刻提示词后台配置体系。

### 4.6 返回任务规则

“返回任务”恢复单图复刻创作页面时，除了恢复现有的：

- 文案
- 参考图
- 商品图
- 商品信息
- 分辨率
- 比例
- 结果图

还需要恢复该次任务实际使用的顶部商品分类。

这条规则尤其用于以下场景：

1. 用户走本地上传商品图路径，未选择已有商品
2. 用户提交时的分类并不是从已选商品自动派生出来的
3. 用户重新打开任务时，页面顶部仍应准确回到当时的分类状态

## 五、页面交互要求

### 5.1 复刻页顶部分类是“生效配置”，不是纯展示

页面顶部商品分类在本次需求里不再只是 UI 展示，而是实际参与业务逻辑：

1. 影响“上传商品图”弹窗的默认查询条件
2. 影响提交时的分类提示词命中
3. 影响返回任务时的页面恢复

但它仍然是**非必填配置项**：

1. 用户可以不选择顶部商品分类直接继续操作
2. 页面和后端都不能因为顶部商品分类为空而阻止提交
3. 顶部商品分类为空时，复刻创作走默认提示词前后缀

### 5.2 用户不需要理解提示词配置细节

对用户而言，他只会看到：

1. 选择顶部商品分类
2. 选择已有商品图或上传本地图片
3. 填写文案并提交

用户不需要知道后台存在：

- 默认提示词前后缀
- 分类提示词前后缀

这些配置细节都由后端和运营配置承担。

### 5.3 自由创作页面不联动本需求

虽然自由创作页面当前也存在顶部商品分类 UI，但本版本不要求：

1. 自由创作按顶部分类命中前后缀提示词
2. 自由创作返回任务恢复顶部分类

本次文档、评审和开发范围全部限定在单图复刻创作。

## 六、非范围说明

本次需求不包含以下内容：

1. 不新增新的商品分类管理后台
2. 不新增新的提示词配置后台
3. 不改单图自由创作的提示词逻辑
4. 不调整现有默认提示词前后缀的内容
5. 不改套图创作
6. 不要求根据本地上传图片内容自动识别商品分类
7. 不要求替换页面顶部商品分类当前使用的数据来源，只要现有分类数据满足业务口径即可

## 七、验收标准

### 7.1 顶部商品分类展示

1. 单图复刻创作页面顶部仍正常展示当前那批“二级分类”选项
2. 顶部商品分类继续复用现有商城分类数据来源
3. 顶部商品分类不是必选项，不选择时页面仍可继续操作

### 7.2 上传商品图弹窗联动

1. 顶部已选分类时，打开“上传商品图”弹窗，分类自动带入查询条件
2. 顶部未选分类时，选择已有商品后，只有当该商品所属分类存在于顶部商品分类可选项中时，才会回填到顶部
3. 选择本地上传图片时，如果顶部已选分类，则后续以该分类为准
4. 选择本地上传图片且顶部未选分类时，允许继续提交

### 7.3 提示词命中

1. 提交复刻任务时，如果用户最终确定了顶部商品分类，则按该分类命中分类提示词
2. 后端不再依赖“通过已选商品反查分类”的旧路径来决定分类提示词命中
3. 分类提示词未配齐时，仍整体回退默认提示词前后缀
4. 顶部商品分类为空时，允许正常提交，并直接走默认提示词前后缀

### 7.4 返回任务

1. 返回任务进入单图复刻创作页时，顶部商品分类能正确恢复
2. 即使该次任务没有选择已有商品、只有本地上传商品图，也能恢复顶部分类状态

### 7.5 范围控制

1. 单图自由创作行为不受本次需求影响
2. 现有复刻提示词后台配置页继续可用，无需新增第二套配置页面
