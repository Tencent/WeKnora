# 提取单视频知识

把一个视频的当前转写转换为可审计的五类知识候选。原文证据是事实源，Skill 负责理解内容和提交候选，服务端负责确定规范对象和规范 Wiki 页面。

## 规则入口

开始处理前完整阅读：

- [type-frameworks.md](references/type-frameworks.md)：五类语义、字段、身份特征和复合对象边界；
- [wiki-schema.md](references/wiki-schema.md)：候选、证据贡献、规范页面、关系和写入契约；
- [audit-rules.md](references/audit-rules.md)：候选去向、语义判定记录、质量状态和完成门禁。

仅在组装输出前完整阅读 [output-examples.md](references/output-examples.md)。样例只用于核对结构，不得把样例内容或 ID 写入 Wiki。

## 输入

输入限定为一个账户空间内的一个知识库、一个视频、一份整篇源文档和一个当前转写代次。使用 **精读源文档**、**查看文档分块**、**阅读 Wiki 页面**、**搜索 Wiki**、**查询知识图谱**、**查看 Wiki 问题**、**标记 Wiki 问题**、**更新 Wiki 问题**、**创建/覆盖 Wiki**。

查看分块时 `limit` 不超过 100，并用 `offset` 读完全部页面。旧代次只用于识别冲突，不提供本轮证据。

## 工作流程

### 1. 确认范围

读取整篇源文档、全部分块、章节、时间范围、视频分类、已有对象页和图谱关系。

完成条件：账户空间、知识库、视频、源文档、转写代次和证据全集唯一且一致。

### 2. 发现候选

覆盖实质话题、定义、实践过程、可复用做法、判断、限制、转折和未决问题。每个候选包含候选 ID、规范标题建议、核心内容、建议类型、身份特征、结构字段、1–3 个对象证据和逐字段证据；被排除章节记录原因。

完成条件：每个实质章节已映射候选或具有明确排除原因。

### 3. 拆解与分类

按 [type-frameworks.md](references/type-frameworks.md) 逐个候选执行“去类型装饰 → 检查复合对象 → 确定对象边界 → 选择唯一类型 → 形成身份特征”。正文分别定义两个对象时拆成两个候选并保留关系依据；无法确定边界时进入 `review_required`。

Skill 只提出规范标题和别名建议，不生成或选择最终知识对象 ID、Wiki 页面 ID 或规范页面 slug。

完成条件：每个候选都有唯一对象边界、唯一建议类型、可比较的身份特征和可审计处理结果。

### 4. 形成证据贡献

按 [wiki-schema.md](references/wiki-schema.md) 为每个候选形成一组当前视频当前代次的 `evidence_contribution`。贡献只保存源文档、证据、分块、时间和字段证据引用，不复制证据正文。

完成条件：每个拟提交候选恰有一组身份一致、可回查的证据贡献；所有非空展示字段均能回溯到该贡献。

### 5. 最终审计

按 [audit-rules.md](references/audit-rules.md) 校验类型门禁、复合对象、证据、正文和当前代次身份，再赋予最终质量状态。`review_required`、`conditional` 和 `failed` 不得作为可信对象发布。

完成条件：每个候选都有最终状态、判定依据和失败或冲突字段，只有 `passed` 进入提交阶段。

### 6. 提交规范写入

通过 `wiki_write_page` 提交完整候选与证据贡献。输入中的候选身份只是提案；写入工具负责召回、语义判定、冲突阻断和规范页面写入。工具返回 `review_required` 时标记问题并停止该候选，不另建页面。

每次成功写入后，按工具返回的规范对象 ID、规范 Wiki 页面 ID、规范标题和 slug 回读。二次关系写入和视频索引只能使用这组返回身份，不得继续使用候选 ID、建议标题或建议 slug。

完成条件：每个已提交候选都有 `created`、`reused` 或 `review_required` 结果；成功对象及关系目标已按返回身份回读，不存在悬空引用。

### 7. 运行摘要

报告五类候选及最终状态数量、规范写入结果、章节覆盖与排除、关系结果、降级和未解决问题。没有人工基准时不报告准确率或召回率。

## 边界

- 五类业务规则只来自本 Skill 及其 references；运行时副本不得独立维护。
- 规范身份和规范页面由服务端写入模块统一确定；Skill 不按标题直接新建对象页。
- 一组候选只携带当前视频当前代次的证据贡献；跨视频贡献聚合与规范页内容合并由服务端完成。
- 场景视图、概览、大纲、总结、Graph 投影和问答属于下游。
- WeKnora 不可用、规则未完整读取、版本不清或写入回读失败时停止相关写入并报告，不宣称完成。
