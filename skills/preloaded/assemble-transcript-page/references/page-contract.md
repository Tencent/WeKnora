# 前台页面契约

```markdown
# 文字稿标题

> 可选的内容质量警示

## 快速概览

一段 150～300 个汉字的总结。

## 语义时间轴
## 内容大纲
## 智能总结
## 相关知识
## 相关文字稿与学习路径
## 证据与质量说明
```

页面首屏应帮助用户判断是否深入学习。大纲是导航界面，智能总结是学习界面，两者不得合并为重复的章节摘要。

## 链接优先级

1. `node-page-registry.json` 中 `standalone` 节点的 `page_path`。
2. 图谱确认的 `source_fragment_url`。
3. 指定知识库 Wiki 中的知识原子或实体，通过 **阅读 Wiki 页面** 获取页面内容，使用知识库原生双链引用（如 `[[汪天凡]]`、`[[从智能到智慧]]`），不使用 `entities.md#V002-ENT-001` 或 HTML 锚点格式。
4. 无可审计定位时显示不可链接的推荐文字，不伪造目标。

相关知识条目必须展示关系类型和一句推荐理由。
