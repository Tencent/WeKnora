# 生成文字稿内容大纲

大纲是前台导航层，不是新的知识提取层。

## 输入

可用工具：**精读源文档**、**查看文档分块**、**阅读 Wiki 页面**、**查看 Wiki 问题**、**创建/覆盖 Wiki**

### 时间戳处理

- 章节时间范围和原文时间戳来源于 **精读源文档** 返回的原始文字稿内容，而非 Wiki 页面。
- 原始文字稿有时间戳时，大纲中每段原文显示 `> **说话人** HH:MM:SS–HH:MM:SS` 格式。
- 原始文字稿无时间戳时，章节时间范围标注 `unknown`，原文段落不显示时间戳，不伪造。

生成前完整阅读 [references/outline-template.md](references/outline-template.md)。

## 工作流程

### 一、建立章节骨架

1. 通过 **精读源文档** 和 **查看文档分块** 确定章节顺序和边界。
2. 保留经审计的陈述性章节标题；如上游标题是反问、设问或其他疑问形式，先回到时间轴阶段修正，不在大纲层静默改名。

### 二、逐章生成内容

对每个章节依次执行步骤 3～7，章节之间相互独立：

3. 为该章选择审计状态清晰的关键知识原子，不重复提取新结论。
4. 生成"本章核心内容"和 2～6 个"关键知识点"，格式见 [references/outline-template.md](references/outline-template.md)。
5. 按说话人和段落顺序展示本章原文。
6. 有真实原文定位链接时提供跳转；否则只显示时间范围。
7. 显示该章的对齐状态和必要警示。

### 三、输出

8. 所有章节内容就绪后，通过 **创建/覆盖 Wiki** 工具将大纲写入知识库的 Wiki 页面。写入契约：工具 `page_type` 用 `index`；页面 frontmatter 必须含 `type: outline`、`source_video_id: {视频ID}` 与 `transcript_generation: {转写代次}`。由 vidsage 内容流水线触发时，页面 slug 固定为 `outline/{视频ID}`，不得使用视频标题或其他产物 slug。

## 强制规则

- 不得只输出 `P001–P008` 而不展示对应原文。
- 原文过长时可在前台默认折叠，但 Wiki 页面中仍必须保存完整实质原文。
- 不得改变原文的主体、语气、范围、因果和确定程度。
- 章节核心内容必须能回指章节 ID 和知识原子 ID。
- 不展示"核心问题"或"本章回答"；章节标题与核心内容已经承担导航和解释作用。
- 将章节的 `topic_tags` 统一展示为"关键词"，不要使用"主题"或"关键主题"标签。
