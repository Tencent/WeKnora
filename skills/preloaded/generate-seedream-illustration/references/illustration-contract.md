# 插画计划契约

`illustration-plan.json` 每项包含：

```json
{
  "id": "ILL001",
  "placement_after_section": "决策路径",
  "knowledge_atom_ids": ["K001", "K004"],
  "visual_purpose": "呈现人物从问题到选择再到结果的路径",
  "visual_structure": "path",
  "must_include": ["选择 A", "限制条件"],
  "must_avoid": ["未经证实的数据"],
  "status": "planned",
  "output_path": null
}
```

优先可视化决策路径、流程、概念关系、观点对比、因果链和知识地图。不为装饰而生图，不强制每章一图。
