# 检索时间轴

从已建立语义时间轴的视频中，通过自然语言描述定位到视频时间范围、文稿段落和证据片段。不生成新知识，只检索和呈现已有产物。

## 数据来源

本 Skill 不直接读取文件，所有数据通过工具调用获取。不修改任何输入数据。

### 通过精读源文档获取

- 段落原文、说话人、时间戳、证据片段
- 语义章节、章节摘要、topic_tags、证据 ID
- 前台聚合章节（可选，用于展示）

### 通过阅读 Wiki 页面获取

- 知识原子（用于反向溯源）
- 实体（用于按人名/机构名检索）
- 关系（可选，用于关联扩展）

## 必读规范

执行前完整阅读 [references/retrieval-contract.md](references/retrieval-contract.md)。

## 检索模式

### 一、关键词/语义描述检索（主模式）

用户用自然语言描述想找的内容，不要求精确匹配。

1. **解析查询意图**：从用户描述中提取关键词、主题、人名、概念等检索信号。
2. **多维度匹配**：同时搜索章节标题、章节摘要、topic_tags、段落原文、证据引文，对匹配结果加权排序。
3. **跨视频搜索**：默认搜索全部已处理视频；用户指定视频时只在指定范围内搜索。
4. **返回定位结果**：每条结果包含视频 ID、章节标题、时间范围、匹配段落原文片段、证据 ID、匹配分数和匹配原因。

### 二、知识原子反向溯源

用户提供知识原子 ID 或通过 Wiki 链接进入，需要定位到原文。

1. 通过 **阅读 Wiki 页面** 获取该知识原子关联的证据 ID 和章节 ID。
2. 通过 **精读源文档** 获取证据片段的引文和时间戳。
3. 通过 **精读源文档** 获取对应章节的摘要和上下文。
4. 通过 **精读源文档** 获取证据关联的段落原文。
5. 返回完整的溯源链：知识原子 → 证据片段 → 章节上下文 → 段落原文 → 时间戳。

### 三、结构化过滤检索

用户按说话人、时间范围、视频等结构化条件过滤。

1. **按说话人**：通过 **精读源文档** 获取说话人信息和段落归属，按说话人过滤。
2. **按时间范围**：指定视频和时间区间（如"前10分钟"），返回该区间内的所有章节和段落。
3. **按视频**：指定一个或多个视频 ID，限制搜索范围。
4. **按章节类型**：通过 **精读源文档** 获取章节的 topic_tags，按主题过滤。

### 四、关联扩展检索

从一个检索结果出发，沿知识图谱扩展关联内容。

1. 从匹配的知识原子出发，通过 **阅读 Wiki 页面** 获取其关联原子和关联实体。
2. 通过 **查询知识图谱** 获取以该原子为端点的关系，沿关系链扩展。
3. 对扩展出的关联原子，重复执行反向溯源，返回关联内容的原文定位。
4. 标注关系类型和关系解释，让用户理解关联逻辑。

## 检索流程

### 第一步：确定搜索范围

1. 通过 **精读源文档** 确认可用的视频及其时间轴审计状态。
2. 排除时间轴未通过审计的视频。
3. 用户指定视频时缩小范围；未指定时全库搜索。

### 第二步：执行检索

根据检索模式，通过 **精读源文档**、**阅读 Wiki 页面**、**搜索 Wiki** 和 **查询知识图谱** 获取数据，由 Agent 完成多维度匹配和加权排序。

### 第三步：结果排序与去重

1. 按匹配分数降序排列。
2. 同一章节内多个段落命中时，合并为一条结果，保留最高分。
3. 跨视频结果按视频分组，组内按时间顺序排列。

### 第四步：输出结果

默认输出 Markdown 格式的人类可读结果；用户要求时输出 JSON 格式供下游程序使用。

## 输出格式

每条检索结果包含：

```markdown

```

## 强制规则

- **只读不写**：不修改任何已有数据，不生成新的知识产物。
- **不编造内容**：检索结果中的原文片段必须来自 **精读源文档** 返回的段落原文，不得改写或补充。
- **时间戳保真**：返回的时间范围必须来自原始数据，不得估算或推算。
- **溯源完整**：从匹配结果到原始段落的溯源链必须完整可验证。
- **去重保序**：同一章节内的多个匹配段落合并展示，不同章节按时间顺序排列。
- **跨视频标注**：多视频结果必须标注视频来源，不得混淆不同视频的章节和段落。
- **置信度可见**：段落对齐状态为 `pending_alignment` 时，在结果中标注时间不确定性。
- **空结果诚实**：无匹配结果时明确告知，不返回近似结果冒充匹配。

## 字段规则

- **匹配分数**：0–1 之间的浮点数，基于关键词命中率、字段权重（标题>摘要>tag>原文>引文）和语义相关度综合计算。
- **原文片段**：截取匹配关键词前后各 50 字的上下文，用 `...` 标注省略。整段不足 100 字时展示全文。
- **说话人标签**：使用 **精读源文档** 返回的说话人名称，不使用内部 ID。
- **时间显示**：统一使用 `HH:MM:SS–HH:MM:SS` 格式，同时保留 `start_seconds` 和 `end_seconds` 数值。

## 失败处理

- 目标视频源文档不可用时，报告缺失并列出已有视频。
- 源文档存在但段落内容为空时，报告数据不完整。
- 用户提供的知识原子 ID 不存在时，列出有效 ID 前缀供参考。
- 说话人名称无法匹配时，列出该视频已知说话人列表。
- 检索无结果时，建议用户调整关键词或扩大搜索范围。
