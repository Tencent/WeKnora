# 检索契约

## 数据获取

本 Skill 不直接读取文件，所有数据通过以下工具获取：

| 工具 | 获取内容 | 检索用途 |
|---|---|---|
| 精读源文档 | 段落原文、说话人、时间戳、语义章节、章节摘要、topic_tags、证据片段 | 关键词匹配、时间范围过滤、说话人过滤、原文溯源 |
| 阅读 Wiki 页面 | 知识原子、实体、关联信息 | 知识原子反向溯源、实体检索、关联扩展 |
| 搜索 Wiki | Wiki 页面语义检索 | 交叉验证同分类实体、补充结构维度 |
| 查询知识图谱 | 实体间的确认关系 | 关联扩展、关系链追溯 |

## 可用性检查

检索前必须确认目标视频的时间轴已通过审计：

1. 通过 **精读源文档** 确认视频的时间轴审计状态。
2. 只有审计通过的视频才可检索。
3. 审计未通过或数据缺失的视频跳过，并在结果中标注。

## 匹配算法

### 关键词提取

从用户自然语言查询中提取检索信号：

1. **实体词**：人名、机构名、产品名、技术名（通过 **阅读 Wiki 页面** 匹配实体）。
2. **主题词**：从查询中提取的关键概念词。
3. **引述词**：用户用引号标注的原话片段。

### 加权匹配

Agent 对每个视频的每个章节，综合以下维度计算匹配分数：

- 章节标题命中权重最高
- 章节摘要命中权重次高
- topic_tags 命中权重中高
- 段落原文命中权重中
- 证据引文命中权重中低

引述词（引号内内容）单独匹配段落原文，命中时该段落分数直接设为最高。

### 分数阈值

- 高置信度匹配：多维度同时命中。
- 一般匹配：单维度命中但语义相关。
- 不纳入结果：无命中维度，但在无结果时提示最近似的低分匹配。

### 去重规则

- 同一章节内多个段落命中时，合并为一条结果，取最高分。
- 同一视频内跨章节命中时，每章独立列出。
- 跨视频结果按视频 ID 分组，组内按时间顺序排列。

## 输出约束

### Markdown 格式

- 每条结果以三级标题开头，格式为 `### [视频ID] 章节标题`。
- 原文片段截取匹配关键词前后各 50 字，用 `...` 标注省略。
- 段落对齐状态非已验证时，在时间范围后追加 `（时间待验证）`。
- 多条结果之间用 `---` 分隔。

### JSON 格式

- 顶层包含 `query`、`total_results`、`results` 三个字段。
- 每条结果包含完整的定位信息：视频、章节、段落、证据、时间戳。
- `matched_atoms` 字段列出该段落/证据关联的知识原子 ID（通过 **阅读 Wiki 页面** 反查）。

## 跨视频搜索规则

- 默认搜索全部可用视频。
- 用户指定视频 ID 时，只搜索该视频。
- 用户指定频道时，搜索该频道下全部视频。
- 结果按视频分组，每组内按匹配分数降序排列。
- 跨视频结果必须标注视频 ID 和标题，不得混淆。

## 关联扩展规则

从知识原子出发的关联扩展，最多扩展两层：

- 第一层：通过 **阅读 Wiki 页面** 获取的直接关联原子。
- 第二层：第一层原子的关联原子（排除已访问的原子，避免环）。

每层扩展结果标注关系路径，如 `K004 →relates_to→ K003 →example_of→ K001`。关系类型通过 **查询知识图谱** 获取。
