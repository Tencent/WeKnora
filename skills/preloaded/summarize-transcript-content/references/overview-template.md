# 内容概览规范

## 输出结构

```markdown

## 快速概览

150～300 个汉字的一段话总结。
```

不输出关键收获、重点关注、推荐章节、适合读者、内容质量提示或其他附加区块。

## 内容要求

用一段自然中文连贯说明：

1. 文字稿关于谁或什么；
2. 它围绕什么核心问题展开；
3. 内容如何推进，包含哪些重要案例或方法；
4. 最重要的认识、学习价值和适用边界。

不要把以上问题写成标签句或列表。结果必须像编辑撰写的内容导读。

## 类型重点

- 人物访谈：人物身份、关键经历、重要选择、独特判断和思维模型。
- 培训：目标学习者、问题、知识推进、方法和重要误区。
- 沙龙：主题、参与者、多方观点、共识、分歧和开放问题。
- 通用内容：核心问题、主张、论证推进、证据、案例和不确定性。
