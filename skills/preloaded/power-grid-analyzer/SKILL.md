# Power Grid Analyzer

对知识库中的电力行业专用文档进行深度结构分析和合规性审查。

## 核心能力

1. **规程审查**: 识别《电力安全工作规程》等标准的执行要点。
2. **操作票生成与校验**: 提取倒闸操作步骤，分析步骤的前后逻辑连贯性。
3. **巡检日志分析**: 提取设备运行参数，发现隐患与异常。
4. **故障研判**: 基于保护动作信息和设备报警日志分析跳闸原因。

## 分析流程

### 1. 业务场景识别
首先获取当前任务所属的电力业务环节：
- 变电运维 / 输电巡检 / 调度运行
- 文档类型（操作票、工作票、故障报告等）

### 2. 合规与逻辑审查
识别并验证：
- 是否满足安规要求的“停电、验电、接地、悬挂标示牌”四项基本安全措施。
- 设备状态转移逻辑（运行 -> 热备用 -> 冷备用 -> 检修）是否闭环。

### 3. 数据与参数提取
重点关注：
- **设备标识**: 线路名称、开关/刀闸编号
- **运行参数**: 电压、电流、温度异常值
- **保护信号**: 动作继电器及保护类型

## 注意事项

- **安全第一**：一切结论必须以《电力安全工作规程》为最高准则。
- 严禁随意猜测设备状态，必须依据原文日志。
