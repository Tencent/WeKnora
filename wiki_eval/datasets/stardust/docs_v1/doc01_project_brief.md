# Stardust Program Brief

The Stardust Program is a deep-space navigation initiative operated by the Skyvault Initiative. Its goal is to stabilize long-range probes using the Psionic Engine.

The Psionic Engine used in Stardust was developed by Acme Corporation under contract SV-14. The engine integrates an Aurora Beacon for calibration and a Helion Crystal power core for sustained field generation.

Dr. Mira Cole is the chief architect for the Psionic Engine. Jonas Reed manages field operations at Borealis Station.

Key program facts:

- Program owner: Skyvault Initiative.
- Primary propulsion subsystem: Psionic Engine PE-7.
- Main test site: Borealis Station in Svalbard.
- Calibration device: Aurora Beacon.
- Power source: Helion Crystal.
