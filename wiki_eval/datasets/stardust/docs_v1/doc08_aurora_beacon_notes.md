# Aurora Beacon Calibration Notes

The Aurora Beacon is a calibration device used by the Psionic Engine PE-7. It synchronizes the Lumen Coil before each test burn and verifies that the Helion Crystal output is stable.

Acme Corporation designed the Aurora Beacon interface, while Northstar Labs provides replacement Lumen Coil assemblies that must pass Aurora Beacon calibration.

If Aurora Beacon calibration fails, Borealis Station control must block the Stardust Program test burn.
