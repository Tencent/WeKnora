# Psionic Engine PE-7 Specification

The Psionic Engine PE-7 is a navigation and propulsion subsystem developed by Acme Corporation. It uses three major components: a Helion Crystal power core, a Lumen Coil field converter, and an Aurora Beacon calibration unit.

The safety threshold for PE-7 field pressure is 42 kPa. When field pressure exceeds 42 kPa, the engine must enter safe-mode and report the condition to Borealis Station control.

The Aurora Beacon calibrates the Lumen Coil before every test burn. If the Aurora Beacon is offline, PE-7 must not start.

The PE-7 design is approved only for Stardust Program test probes and is not approved for Nightfall Protocol vehicles.
