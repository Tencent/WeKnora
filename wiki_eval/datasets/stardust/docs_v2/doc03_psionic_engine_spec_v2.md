# Psionic Engine PE-8 Updated Specification

The Psionic Engine PE-8 replaces PE-7 for new Stardust Program test probes. Acme Corporation developed PE-8 after the Borealis Station incident review.

PE-8 keeps the Helion Crystal power core and Aurora Beacon calibration unit, but replaces Lumen Coil batch LC-19 with certified LC-22 assemblies from Northstar Labs.

The safety threshold for PE-8 field pressure is 48 kPa. When field pressure exceeds 48 kPa, the engine must enter safe-mode and report the condition to Borealis Station control.

The Celestial Review Board approved PE-8 for Stardust Program Phase Beta on 2032-06-02.
